# 测试你适合什么副业 ✨

一个温暖治愈系的副业测试网站（小红书风格）。纯静态，无需登录，密码进入，24 题 × 4 选项 → 16 种副业结果 + 四维分析 + 行动建议。

## 快速开始

纯静态页面，**无需安装任何东西**，任选其一：

- **直接打开**：双击 `index.html` 用浏览器打开即可。
- **本地预览**（可选）：在项目目录运行 `python3 -m http.server 8000`，然后访问 `http://localhost:8000`。

## 进入密码

- **默认密码：`8888`**
- 修改方式：编辑 [js/data.js](js/data.js) 顶部的 `ACCESS_PASSWORD` 常量即可。

> 说明：密码是前端校验，主要起到「仪式感 / 防误入」作用。懂技术的人可以绕过，若需要真正的安全校验，需要后端或 Serverless（可另加）。

## 内容结构（都在 [js/data.js](js/data.js)，改这里即可）

| 数据 | 说明 |
| --- | --- |
| `ACCESS_PASSWORD` | 进入密码 |
| `DIMENSIONS` | 四个维度（创意力 / 社交力 / 执行力 / 洞察力）的名称、描述、高中低三档文案与建议 |
| `QUESTIONS` | 24 道题，每题 4 个答案，每个答案的 `dim` 指向四个维度之一 |
| `RESULTS` | 16 种副业结果，含 `profile`（四维画像）、`why`、`firstStep`、`monetize`、`pitfall` |

## 计分逻辑

1. 每题选中一个答案，为该答案对应的维度 `+1` 分。
2. 四个维度原始分（各 0~24）通过「6 分为中性 50 分」映射到 0~100。
3. 与 16 种副业的四维画像做欧氏距离匹配，距离最近者即最适合的副业；`契合度 = 100 - 距离`。

## 文件清单

```
index.html      页面结构（密码门 / 介绍 / 答题 / 结果）
css/style.css   温暖治愈系样式（改顶部 CSS 变量可整体换肤）
js/data.js      所有文案与数据
js/app.js       交互、计分、四维雷达图
```

## 常用改动

- **换皮肤**：改 [css/style.css](css/style.css) 顶部 `:root` 里的颜色变量。
- **改题目 / 结果**：直接编辑 [js/data.js](js/data.js)。
- **改雷达图颜色**：在 [js/app.js](js/app.js) 的 `drawRadar` 中搜 `#F2918B`（你）和 `#A8C6A3`（理想）。
- **改分享图**：分享图由 [js/app.js](js/app.js) 的 `drawShareCard` 用 Canvas 绘制（1080×1440），想调整布局、文案或配色都改这里。
